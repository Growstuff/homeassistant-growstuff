# Growstuff - Home Assistant Integration

Add your [Growstuff](https://www.growstuff.org/) outdoor plants and view progress in home assistant!

## Overview

Welcome to the **Growstuff Home Assistant Integration** repository! This project is designed to integrate the Growstuff.org with Home Assistant, allowing you to monitor your garden environment directly from your smart home setup.

---

## Feature
- **Plantings:** Visiblity of progress
- **Activities:** As todo items
- **Gardens**: Individual beds as specific areas
---

## Getting Started

### Prerequisites

- A working **Home Assistant** instance.
- A growstuff account
- Basic knowledge of Home Assistant configurations.

### Installation
### Install this integration

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-41BDF5.svg?style=for-the-badge)](https://github.com/hacs/integration)

#### Via HACS
* Add this repo as a ["Custom repository"](https://hacs.xyz/docs/faq/custom_repositories/) with type "Integration"
* Install
* Restart Home Assistant

#### Manual Installation
* Copy the entire `custom_components/homeassistant-growstuff/` directory to your server's `<config>/custom_components` directory
* Restart Home Assistant
