# Growstuff - Home Assistant Integration

Add your [Growstuff](https://www.growstuff.org/) outdoor plants and view progress in home assistant!

## Overview

Welcome to the **Growstuff Home Assistant Integration** repository! This project is designed to integrate the Growstuff.org with Home Assistant, allowing you to monitor your garden environment directly from your smart home setup.

---

## Feature
- **Plantings:** Visiblity of progress

---

## Getting Started

### Prerequisites

- A working **Home Assistant** instance.
- A growstuff account
- Basic knowledge of Home Assistant configurations.

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/growstuff/growstuff-homeassistant.git
   ```
2. Copy the directory to /usr/share/hassio/homeassitant/custom_components

---

## Configuration

### Basic Setup

1. Add the Growstuff integration to your custom components directory and restart HA
2. Add the Integration.
